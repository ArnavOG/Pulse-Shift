# Pulse Shift

Pulse Shift is a browser-based dimensional survival game built using HTML, CSS, JavaScript, and the HTML5 Canvas API.

The objective is simple: survive for as long as possible by moving through the arena, switching between dimensions, and avoiding incoming hazards. As the game progresses, the challenge becomes more intense and requires quick decisions and accurate movement.

## Features

* Canvas-based gameplay
* Two playable dimensions: Pulse and Void
* Dimension switching mechanic
* Moving obstacles and incoming hazards
* Keyboard controls using WASD and Arrow keys
* Spacebar control for switching dimensions
* Mobile joystick controls
* Mobile dimension-shift button
* Score and best-score tracking
* Start screen and game-over screen
* Responsive layout for desktop and mobile devices
* Futuristic visual design with neon-inspired styling

## Controls

### Desktop

| Action           | Control            |
| ---------------- | ------------------ |
| Move             | WASD or Arrow keys |
| Switch dimension | Spacebar           |

### Mobile

| Action           | Control            |
| ---------------- | ------------------ |
| Move             | On-screen joystick |
| Switch dimension | SHIFT button       |

## How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Launch `index.html` in a modern web browser.

You can also use a local development server, such as the Live Server or Live Preview extension in Visual Studio Code.

## Development
